# SpeakFlow · 英语口语陪练 🎙️

一个本地运行的 AI 英语口语练习应用:和 AI 语音对话、逐句纠错打分、影子跟读、生词积累,目标是从日常交流练到接近母语表达。

所有学习数据只保存在你自己的浏览器里,不经过任何第三方(除了你主动调用的 DeepSeek API)。

## 快速开始

```bash
npm install     # 首次运行需要(本目录已装好依赖可跳过)
npm run build   # 首次运行需要(dist 已构建好,可跳过)
npm start       # 启动,然后浏览器打开 http://localhost:3000
```

### 配置 DeepSeek API Key(二选一)

1. **网页里填(推荐)**:打开应用 → 左下角「设置」→ 粘贴 Key(存于本浏览器 localStorage)
2. **`.env` 文件**:在项目根目录 `.env` 中填入,然后重启 `npm start`

```env
DEEPSEEK_API_KEY=sk-你的key
```

> 还没填 Key 时,可以在地址栏加 `?demo=1` 进入演示模式,预览全部交互(返回模拟数据,不消耗额度)。

## 功能

| 模块 | 说明 |
|------|------|
| 💬 情景对话 | 34 个精选场景(日常生活 / 旅行出行 / 职场专业 / 观点讨论),每个场景有专属 AI 人设、开场白、关键句和词汇;也可用 AI 定制任意场景(如"和房东谈续租""给外国朋友解释中医") |
| ✍️ 即时教练点评 | 每次发言后自动给出:更正版、逐条语法/用词修改(中文解释)、更地道的替代表达、0-100 评分,可一键收藏好句子 |
| 🎙️ 影子跟读 | **两大句库**:① 精选 362 句 · 28 个句包(功能句型/场景高频/职场专业/母语味/发音专项,参照 Cambridge/Oxford 教材体系);② **教材句库 32,832 句**(来自开源语料 Tatoeba 的英中对照句,按词频分四级 + 11 个话题标注,支持中英文搜索,懒加载不占首屏)。听原声(可慢速)→ 跟读 → 逐词对比打分;支持**录音回放**与原声 A/B 对比;AI 可无限出新句子 |
| 🔧 AI 发音诊断 | 跟读后针对你读错/漏读的词,给出音标、可能的错误原因、中文口型要点,并生成针对该音的练习句 |
| 📖 词汇表 | **30,000 高频词**(来自开源词典 ECDICT):音标 + 中文释义 + 考级标签(四六级/考研/高考/托福/雅思/GRE/Oxford3000),可朗读、一键加入生词本、**跳转到教材句库找例句跟读** |
| 📚 生词本 | 对话中点 ⭐ 收藏,AI 一键讲解(释义/词性/例句/搭配),闪卡间隔复习(1/2/4/8/15/30 天记忆曲线) |
| 📈 学习进度 | 连击天数、累计时长、对话轮次、14 天柱状图、最近练习记录 |

- **语音输入**:基于浏览器 Web Speech API(免费),点麦克风说话,实时转文字
- **AI 朗读**:回复自动朗读(可关),支持调整语速 0.6x–1.3x、选择系统语音
- **难度适配**:A2 / B1 / B2 / C1 四档,AI 据此调整语速和用词

## 使用建议

- **浏览器**:推荐 Chrome / Edge(语音识别支持最好);Safari 可用但识别稳定性一般
- **麦克风权限**:首次点击麦克风时允许权限;页面需通过 `localhost` 或 HTTPS 访问(本应用默认满足)
- **练习方法**:每天 15–30 分钟——先跟读 5 句热嘴,再选一个场景对话 10 分钟,重点看教练点评里的「更地道」表达并收藏,睡前用闪卡过一遍生词
- **手机使用**:同一局域网下,手机浏览器访问 `http://<你电脑的IP>:3000` 即可(注意:非 localhost 时浏览器会禁用麦克风,语音输入需在电脑上使用)

## 常见问题

- **提示 "API Key 无效"**:检查 Key 是否以 `sk-` 开头、账户是否有余额;在设置里点「测试连接」验证
- **点麦克风没反应**:确认浏览器已授权麦克风;确认使用的是 Chrome/Edge
- **识别结果为空**:说话声音太小或网络不稳,识别服务需要联网
- **修改了 `.env` 不生效**:需要重启 `npm start`
- **端口占用**:`PORT=8080 npm start` 换端口

## 开发

```bash
npm run dev      # 前端开发模式(vite,localhost:5173,需另开终端跑 npm run server)
npm run server   # 仅启动后端(默认 3000 端口,可用 PORT 环境变量覆盖)
npm run typecheck
npm run build
```

技术栈:React 18 + TypeScript + Vite(前端),Express(本地服务,代理 DeepSeek 流式接口),无其他运行时依赖。语音识别/合成使用浏览器原生 Web Speech API。UI 参考 shadcn/ui 设计风格(slate/blue 中性色板、8px 圆角、细边框、克制阴影)。

```
speakflow/
├── server/index.mjs        # 本地服务:静态托管 + DeepSeek 代理(SSE 流式)
├── scripts/build-corpus.mjs # 教材句库生成脚本(Tatoeba 语料 → 分级标注 JSON)
├── scripts/build-vocab.mjs  # 词汇表生成脚本(ECDICT SQLite → 高频词 JSON)
├── src/
│   ├── lib/                # ai(DeepSeek 客户端)、speech(语音)、diff(发音对比)、coach(提示词)、store(存储)
│   ├── content/            # scenarios(34 个场景)、drills(28 精选句包)、corpus.json(3.2 万教材句)、vocab.json(3 万高频词)
│   ├── views/              # Talk 对话 / Drill 跟读 / Vocabulary 词汇 / Words 生词本 / Progress 进度
│   ├── components/         # Settings 设置面板
│   └── styles.css          # 设计系统(画布式布局,Learnify 风格仪表盘,浅蓝主色)
└── .env                    # DEEPSEEK_API_KEY 填这里
```
